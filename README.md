## Da Roça

Este é o website para a empresa fictícia Da Roça - uma empresa de entregas de produtos orgânicos.

Tecnologias usadas:
- **Front-end**: HTML, CSS e JavaScript;
- **Back-end**: Node.js e Express;
- **Banco de dados**:SQL Server Management Studio (SSMS). 

A conexão ao banco é feita por meio de uma API REST construída com Node.js e Express. As rotas GET, POST, PUT e DELETE possibilitam visualização de produtos, cadastro e login de clientes (JWT para segurança) e feedbacks sobre a empresa e os produtos na página de comentários.

Para rodar o projeto:
-Navegue até a página API-DAROCA: `cd API-DAROCA`
-Instale as dependências: `npm install`
-E inicie o programa: `node index.js`
